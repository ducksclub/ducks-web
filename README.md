# Duck's GameClub Frontend

## Telegram Login OIDC

Frontend starts Telegram Login through OpenID Connect Authorization Code Flow with PKCE.

Required frontend env:

```dotenv
NUXT_PUBLIC_TELEGRAM_LOGIN_CLIENT_ID=1234567890
```

Backend must expose:

```http
POST /api/auth/telegram/oidc
```

Request body:

```json
{
  "code": "<telegram_authorization_code>",
  "codeVerifier": "<pkce_code_verifier>",
  "redirectUri": "https://YOUR_DOMAIN/auth/telegram/callback",
  "nonce": "<nonce>"
}
```

BotFather setup:

`@BotFather` -> `Bot Settings` -> `Web Login` -> `Allowed URLs`

Production:

```text
https://YOUR_DOMAIN/auth/telegram/callback
```

Local testing should use an HTTPS tunnel, for example ngrok:

```text
https://YOUR_NGROK_DOMAIN/auth/telegram/callback
```

The callback URL must exactly match the `redirect_uri` generated by the frontend.
